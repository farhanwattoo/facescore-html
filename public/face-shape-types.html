顔型7種類 診断ガイド｜Oval・Round・Square・HeartをJP+ENで図解

公開日: 2026年5月28日ハブ: 顔のパーツ完全解説実践: 顔型に合う髪型・メイク

What face shape do I have? という英語検索にも、日本語の「顔の輪郭7種類」にも答えられるよう、このページではフェイスシェイプ分類をJP+EN で整理します。AIは forehead width、cheekbone width、jaw width、face length を使って、どの型に近いかを推定します。

顔型の読みやすさチェック

輪郭分類の安定性を確認する

顔型は前髪、サイドの髪、カメラ距離に強く左右されます。輪郭が見えているか、顎が切れていないか、余白が極端でないかを先に確認してから分類を見るとブレを減らせます。

輪郭分類が安定しそうかどうかを簡単にチェックできます。

7つの顔型はどの比率で分かれる？

顔型は、額、頬骨、顎のどこが最も広いかと、顔の長さが横幅に対してどれくらいあるかで大まかに分かれます。Oval は cheekbones が少し広く、jaw が自然に細くなる形です。Round は width と height が近く、輪郭がやわらかく見えやすい型。Square は forehead と jaw width が近く、顎角が立ちやすい型です。

Heart は forehead が比較的広く、chin が細めに見えます。Diamond は cheekbones が強く、額と顎が狭め。Oblong は縦長で sides が比較的まっすぐに見え、Triangle は jaw が広めで lower face に重心が出やすい型です。現実の顔はこの7つにぴったり収まるというより、近いカテゴリに寄せて読むことが多いです。

Oval / 卵型 はなぜ標準扱いされやすい？

卵型は、頬骨が適度に広く、顎に向かって自然に細くなるため、極端な違和感が出にくい分類です。多くのスタイルを合わせやすいことから、説明の基準として扱われることがよくあります。ただし「卵型が正解」という意味ではありません。あくまで他の型を比較する出発点として使いやすいだけです。

Round / 丸型 と Square / 四角型 はどう違う？

どちらも幅の印象が出やすい点では似ていますが、Round は曲線的、Square は直線的です。丸型では頬が中心になりやすく、四角型では顎角が存在感を持ちやすいです。髪型やシェーディングの考え方もここで変わります。丸型は縦ラインを作るとすっきり見えやすく、四角型はサイドと顎角の見え方の扱いがポイントになります。

Heart / Diamond / Triangle は重心の位置を見る

Heart は上重心、Triangle は下重心、Diamond は中央重心と捉えるとわかりやすいです。Heart 型では額から頬にかけて存在感があり、顎先は細く見えやすいです。Triangle 型では jaw の幅が目立ちやすく、Diamond 型では cheekbones の存在感が最も出やすくなります。これらの違いは、前髪やサイドの髪でかなり調整できます。

AI分類で顔型がズレる理由

顔型分類は、輪郭点がどこに置かれたかでかなり変わります。近距離の自撮りでは鼻が前に出て輪郭が狭く見えやすく、逆に広角歪みで下顔面が広がることもあります。前髪が額幅を隠す、輪郭に髪がかかる、顎先が切れると、AIの分類は簡単にズレます。だから顔型は単独の真実というより、撮影条件を含めた読みの結果だと理解するのが大事です。

顔型をどう活かすか

顔型を知る価値は、優劣を決めることではなく、髪型、分け目、フレーミング、余白設計がしやすくなる点にあります。実践寄りに進みたいなら 顔型に合う髪型・メイク、輪郭の比率をもっと技術寄りに見たいなら 顎・フェイスライン診断 を読むとつながりやすいです。

FAQ

顔型は1つに決まりますか？

必ずしも決まりません。実際には中間タイプが多く、「卵型寄りの丸型」「ハート寄りのダイヤ型」のような読み方が自然です。

AIの顔型分類は正確ですか？

正面写真で条件がそろっていれば参考になりますが、髪、角度、距離の影響を強く受けます。固定ラベルというより、写真上の見え方を整理する道具として使うのがよいです。

英語検索にも対応していますか？

はい。このページでは face shape types oval round square heart などの英語ラベルも併記し、JP+EN どちらの意図でも読みやすい構成にしています。
